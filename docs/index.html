Ingest

A GitHub Action fetches the last 48 hours of hourly readings from Open-Meteo's Air Quality API every hour and commits the raw JSON to this repo.

Transform

DuckDB runs three SQL steps in memory — bronze (typed Parquet), silver (deduped, quality-checked), gold (NAQI and aggregations) — and writes the results back as Parquet + JSON.

Serve

This dashboard is a static site on GitHub Pages that fetches the pre-computed JSON. No servers, no databases, no cost.
